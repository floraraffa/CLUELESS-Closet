# CLUELESS Closet

Lens Studio / Spectacles prototype for scanning clothing, saving wardrobe cards, and building toward AI outfit recommendations.

## Open

Open `CLUELESS-Closet-main.esproj` in Lens Studio.

## Notes

- `Cache/` and `PluginsUserPreferences/` are intentionally ignored.
- Supabase is currently a disconnected template. Configure a new Supabase project before cloud sync.
- Local wardrobe saving should work independently from Supabase.
